# DevDock v1.1.10

## Highlights

- Split PostgreSQL connection settings into separate database and default schema fields.
- Fixed PostgreSQL schema switching so selecting a schema no longer changes the connected database name.
- Added PostgreSQL search path setup for selected schemas, with `public` kept available as a fallback.
- Preserved compatibility for older PostgreSQL connections where the database name had also been stored as the schema.

## Verification

- `npm run typecheck`
- `npm run build`

## Notes

- Package metadata and lockfile were updated for version `1.1.10`.
