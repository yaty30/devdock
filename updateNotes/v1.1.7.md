# DevDock v1.1.7

## Highlights

- Added Git repository mode for projects with a separated frontend directory.
- Auto-detected whether separated frontend/backend directories share one Git root or use independent repositories.
- Added separate Frontend and Backend Git settings when a project uses separate repositories.
- Added a Git terminal repository selector for separate frontend/backend repositories.
- Preserved single-repository Git terminal behavior for normal projects and separated frontends inside the same repo.
- Improved invalid Git directory feedback in the Git terminal.
- Normalized generated Python virtual environment activation commands for macOS and Linux shells.

## Verification

- `npm run typecheck`
- `npm run build`

- Package metadata and lockfile were updated for version `1.1.7`.
