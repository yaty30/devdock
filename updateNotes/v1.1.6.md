# DevDock v1.1.6

## Highlights

- Added Redux Toolkit and React Redux as the foundation for shared app state.
- Introduced a typed renderer store, typed Redux hooks, and the first navigation slice.
- Reduced `App.tsx` to the provider entry point and moved shell composition into app-level hosts.
- Extracted app shell ownership into focused hooks for bootstrap, runtime events, feature flags, macOS window state, sidebar resize sync, and splash lifecycle.
- Extracted feature controllers for projects, dashboard state, and tools to continue separating workflows from shell rendering.
- Added `HeaderHost`, `MainRouteRenderer`, and `AppModalHost` to isolate header, route, and modal rendering decisions.
- Centralized dirty settings navigation handling through `useNavigationGuard` and updated database navigation to use the shared guard request.

## Verification

- `npm run typecheck`

## Notes

- Package metadata and lockfile were updated for version `1.1.6` and the new Redux dependencies.
- The existing unrelated `src/renderer/src/styles.css` change was left untouched.
