# DevDock v1.1.8

## Highlights

- Added editing support for environment variable names in project `.env` files.
- Added environment variable row creation and deletion in the `.env` file modal.
- Added validation for empty or invalid `.env` variable names and values before saving.
- Preserved `.env` comments and quoting behavior while updating edited variables.
- Improved `.env` modal table and footer layout for editable rows and row actions.
- Refined app header spacing, route loading layout, terminal sizing, and build action disabled states.

## Verification

- `npm run typecheck`
- `npm run build`

## Notes

- Package metadata and lockfile were updated for version `1.1.8`.
